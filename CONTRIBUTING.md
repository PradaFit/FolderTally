# Contributing

Bug reports and feature requests are welcome. Use synthetic data and redact private paths from screenshots. Report security issues privately as described in [SECURITY.md](SECURITY.md).

Code contributions are not accepted until a contributor licensing process is established. Do not submit code, patches, or copied third-party implementations in issues or pull requests. This keeps ownership and future commercial licensing clear.

Personal modifications are permitted under [LICENSE](LICENSE). Permission to modify a copy does not mean that upstream code contributions can be accepted. A contributor agreement will be documented before that policy changes.
